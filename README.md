# مِداد (Medad) — mobile-first RTL frontend

Next.js 14 (App Router) + Tailwind CSS 3 + lucide-react. UI only, no backend.

```bash
npm install
npm run dev      # http://localhost:3000  → redirects to /challenges
```

Routes: /challenges · /learn · /compete · /friends · /profile
Design tokens (colors, shadow, font) live in `tailwind.config.js`.
